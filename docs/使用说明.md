# SinUpdateHub · 使用说明

> 一个管理「本机装了哪些软件、各自有没有新版本」的小工具，支持 **GitHub Releases** 与 **WinGet** 两类来源，一键检查更新、下载安装包并启动安装器，清单可备份到 WebDAV。

---

## 一、它能做什么

| 能力 | 说明 |
|---|---|
| 软件清单 | 每条记录包含：项目名称 / 包 / 当前版本 / 新版本 / 安装目录 / 来源 |
| GitHub 来源 | 填仓库地址，自动读取最新 Release 版本号；再用「包」字段的字符或正则在 Assets 里自动匹配安装包文件名 |
| WinGet 来源 | 填 WinGet 包 ID，直接读微软官方清单仓库 `microsoft/winget-pkgs` 的最新版本与安装包直链（**本机不装 winget 也能用**） |
| 当前版本自动识别 | 从注册表卸载项识别已安装版本，识别不到再读安装目录里 exe 的文件版本；都不行可手填 |
| 检查更新 | 顶部「检查全部更新」，逐条显示：检查中 / 已是最新 / 有可更新 / 失败原因 |
| 更新 | 下载匹配到的安装包 → 自动启动安装器（每条可单独配置安装参数）→ 安装后确认是否把当前版本标记为新版本 |
| 备份 | WebDAV 上传/下载清单；也能导出/导入本地 JSON |

## 二、快速开始

1. 双击 `SinUpdateHub.exe`（免安装、不需要 .NET 运行时）。
2. 点「添加软件」，选择来源：
   - **GitHub 来源**：仓库地址填 `https://github.com/owner/repo`，「包」填安装包文件名里的关键字符，例如 `Setup.exe`。
   - **WinGet 来源**：**不用记包 ID**——填好项目名称（如 `UU远程`）后点「搜索包 ID」，或直接点「自动识别」，软件会从本地 WinGet 索引里按名称找到 `NetEase.UURemote` 并自动填入。
   - **官网/手动来源**：WinGet 清单和 GitHub 都没有的软件用这个（例如 NVIDIA Broadcast）。填「官网下载页」即可；检查时只刷新本机当前版本，「更新」= 打开官网下载页由你手动安装。
3. 点「自动识别」自动填「当前版本」和「安装目录」（也可手填）。
4. 点「保存」，回到表格点「检查全部更新」。
5. 表格里「新版本」列为紫色时，点该行「更新」→ 下载安装包 → **自动运行安装器**（不再弹「是否立即运行」的确认框）→ 安装完成后软件会自动重扫注册表/文件版本并回填「当前版本」，状态随之变成「已是最新」。
   - 如果该条目的「安装目录」是空目录/不存在（还没装或绿色软件）：会**创建并打开该安装目录**；
     - 下载的是压缩包（zip/7z/rar）：**另外再打开下载目录**（方便解压后放进安装目录），不再自动跑安装器；
     - 下载的是 exe/msi：继续运行安装器，安装位置可以直接粘贴刚打开的目录路径。
   - 点「检查」= 先刷新**本机当前版本**（绑定的 exe / 安装目录里的 exe / 注册表），再查远端**新版本**，所以手动升级过之后点检查能立即对上新版本。
   - 更新失败时会弹框说明原因；**点「确定」后会自动打开下载页面**（WinGet 打开官网，GitHub 打开 Releases），可直接手动下载安装。
6. 操作列：「更新 / 检查 / 编辑 / 删除 / ⋯」，其中 **⋯ 是左键点开的菜单**（打开安装目录、打开发布页、复制信息）。发布页：GitHub 打开 Releases，WinGet 打开该包在 winget-pkgs 里的清单目录。

> 主界面是**表格式**：项目名称 / 包 / 当前版本 / 新版本 / 安装目录 / 来源 / 状态 / 操作，一屏看全。
> 上方有两排筛选：第一排按状态（全部 / 可更新 / 已最新 / 失败 / 未检查），第二排按**来源**（全部来源 / GitHub / WinGet），可叠加使用，也可配合搜索框。

## 三、字段说明

| 字段 | 说明 | 例子 |
|---|---|---|
| 项目名称 | 显示名，随便起但建议好认 | `FreeType`、`UU 远程` |
| 来源 | GitHub / WinGet / 官网·手动 | `GitHub` |
| 仓库地址 | 仅 GitHub 来源；支持 `https://github.com/owner/repo`、`owner/repo` | `https://github.com/OUBIGFA/FreeType` |
| 包 | GitHub：Assets 文件名筛选；WinGet：包 ID（可搜索自动填） | `Setup.exe` / `NetEase.UURemote` |
| 正则匹配 | 勾选后「包」按正则解释（如 `^FreeType-.*-Setup\.exe$`） | |
| 当前版本 | 安装电脑上的版本，可自动识别 | `0.1.8` |
| 安装目录 | 可自动识别，也可手选；识别不到版本时用「选 EXE」直接挑主程序，会自动填目录并读出版本；**绑定后该条目的当前版本永远从这个 exe 读**（可在编辑窗口「解除绑定」） | `D:\files\FreeType` |
| 安装参数 | 可选，静默安装时用 | `/S`、`/SILENT`、`/VERYSILENT` |
| 备注 | 可选 | |

### 「包」筛选规则（GitHub 来源）

- 默认是**包含匹配、不区分大小写**：`Setup.exe` 能命中 `FreeType-0.1.8-Setup.exe`，也能命中 `...-Setup-x64.exe`。
- 支持竖线或空格分隔多个关键字，任一命中即算命中：`x64 setup`。
- 勾选「正则匹配」后可写正则：`^FreeType-.*-Setup-x64\.exe$`。
- **留空** = 自动挑最像安装包的那个（优先 .exe/.msi、x64、名字带 Setup/Installer，排除 .sha256/.sig 等校验文件）。
- 匹配到多个时，该行「改选」可以手动挑。

### 官网/手动来源（WinGet、GitHub 都没有的软件）

- 例子：NVIDIA Broadcast —— winget 官方清单里没有它（NVIDIA 只提交了 RTX Voice 等），GitHub 也没有仓库。
- 用法：添加软件 → 选「官网/手动」→ 填项目名称 + **官网下载页**（如 `https://www.nvidia.cn/geforce/broadcasting/broadcast-app/`）→ 点「自动识别」读本机当前版本和安装目录 → 保存。
- 「检查」：刷新本机当前版本；因为官网没有标准版本接口，状态显示「手动更新」。
- 「更新」：直接打开官网下载页，你下载安装后点「检查」刷新版本即可。

### WinGet 包 ID 怎么来（WinGet 来源）

- 点「搜索包 ID」，输入软件名称或关键词（`UU远程`、`微信`、`7zip`、`NetEase` 都行），从 WinGet 官方索引里选一个即可。
- 或者先填项目名称，然后点「自动识别」——软件会按名称自动匹配并填入包 ID（唯一高分匹配时才自动填）。
- **改了项目名称后，之前自动搜出来的包 ID 会自动清空**并提示重新搜索，避免名称和包对不上。
- 首次搜索需要下载约 21 MB 的 WinGet 本地索引（设置页「WinGet 本地索引」可手动更新）。有了这份索引，WinGet 检查更新也不再消耗 GitHub API 额度。

## 四、设置（主界面左侧「设置」页）

- **代理**：默认跟随 Windows 系统代理；国内直连 GitHub 失败时，选「手动填写代理地址」填 `http://127.0.0.1:7897`。
- **测试网络**：点一下，按钮下方直接显示结果（GitHub API 剩余额度、raw.githubusercontent 是否可达、WinGet 索引状态）。
- **GitHub API Token**（掩码显示）：GitHub 匿名请求限 **60 次/小时**（按 IP，GitHub 来源和 WinGet 都算）；填 Token（登录态）后提升到 **5000 次/小时**。粘贴后点「验证」，成功会在下方显示「已登录：你的用户名（额度 a/b）」；也可以点「打开 Token 页面」一键去 GitHub 创建（不需要勾任何权限）。
- **启动时自动检查**：打开软件后自动检查一遍。
- **以管理员身份运行安装器**：默认开启（会弹 UAC）。
- **WinGet 本地索引**：显示状态并可手动更新（约 21 MB）。

## 五、备份与恢复（主界面左侧「备份与恢复」页）

支持坚果云、Nextcloud、群晖、Alist 等标准 WebDAV 服务（地址栏已默认填好坚果云：`https://dav.jianguoyun.com/dav/`）。

1. 主界面左侧点「备份与恢复」。
2. 填 WebDAV 地址（默认已是坚果云）、账号（**完整邮箱**）、密码。
   - **坚果云必须用「应用密码」，不是登录密码**：网页版 → 右上头像 → 账户信息 → 安全选项 → 添加应用 → 生成应用密码（16 位小写字母+数字）。页面上有「如何获取应用密码」按钮直达帮助页。
   - 密码框可勾选「显示密码」核对是否粘贴完整。
3. 点「测试连接」（失败时下方会直接列出 401 的具体排查点）→「立即备份」。
   - 每次「立即备份」只生成**一条**时间戳快照（`data-日期-时间.json`），旧快照按「保留备份数」自动清理。
4. 换电脑后，填同样的 WebDAV 配置 → 点「刷新列表」→ 选中一个备份 →「恢复选中备份」。

> 密码/Token 用 Windows DPAPI 加密后保存在本机，不会明文落盘。

也可以「导出 JSON」把清单存成文件，自己丢进 GitHub 仓库做异地备份，换机时「导入 JSON」。

## 六、数据存放位置

| 内容 | 路径 |
|---|---|
| 软件清单 | `%APPDATA%\SinUpdateHub\data.json` |
| 设置（含加密后的密码） | `%APPDATA%\SinUpdateHub\settings.json` |
| 下载缓存 | `%LOCALAPPDATA%\SinUpdateHub\downloads` |
| 日志 | `%APPDATA%\SinUpdateHub\logs\app.log` |

## 七、常见问题

**Q：检查失败提示 GitHub API 限流？**
A：GitHub 匿名只给 60 次/小时（按 IP 算）。设置页粘贴 API Token 并点「验证」，可用额度会变成 5000 次/小时；也可以等一小时后自动恢复。软件会提示恢复时间。

**Q：WinGet 来源提示「清单里找不到包 ID」？**
A：别手输 ID——点「搜索包 ID」按软件名称搜（或填项目名称后点「自动识别」），从结果里选一个即可。

**Q：点更新没反应 / 安装器没弹出来？**
A：看日志 `%APPDATA%\SinUpdateHub\logs\app.log`；有些安装器（如 MSIX）需要手动双击安装，软件会把文件所在目录打开。

**Q：WebDAV 一直提示 401「账号或密码不被接受」？**
A：① 坚果云必须用「应用密码」而不是登录密码；② 账号要填完整邮箱；③ 密码框勾选「显示密码」核对是否粘贴完整（应用密码一般是 16 位小写字母+数字）。仍失败时把错误信息贴给我。

**Q：自动识别不到版本？**
A：绿色/便携软件通常没有注册表记录，手动填版本号即可。

**Q：软件清单能备份到 GitHub 吗？**
A：目前备份只支持 WebDAV + 本地 JSON；把导出的 JSON 放进 GitHub 仓库即可实现「GitHub 备份」。
